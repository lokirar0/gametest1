# Rail Mayhem: Depot to Depot

Аркадная 3D-игра для браузера и Windows: ведите детализированный поезд через пустынный маршрут, спасайте пассажиров и отбивайтесь от бандитов. На пути открываются боевая турель и финальная волна; между рейсами можно улучшать поезд в депо и тратить заработанные монеты в казино.

## Разработка в браузере

Требуется Node.js 20 или новее.

```bash
npm ci
npm run dev
```

Откройте адрес, который Vite покажет в терминале (по умолчанию `http://localhost:3000`).

## Запуск как приложение Windows

Для разработки в отдельном окне приложения:

```bash
npm ci
npm run desktop:dev
```

Для создания Windows-файлов запуска:

```bash
npm ci
npm run desktop:build
```

Готовые файлы появятся в папке `release`: `Rail-Mayhem-<версия>-<архитектура>.exe` запускается без установки, а `Rail-Mayhem-Setup-<версия>-<архитектура>.exe` устанавливает игру и создаёт ярлыки. Для сборки требуется Windows и Node.js 20 или новее.

Для проверки production-сборки:

```bash
npm run typecheck
npm run build
```

## Управление

- `W` / `↑` — разгон; `S` / `↓` — тормоз; `Space` — экстренное торможение.
- Мышь — прицел; левая кнопка — стрельба (турель открывается во втором акте).
- `R` — починить ближайший повреждённый вагон; `E` или `Q` — гудок.

Доведите поезд до депо, сохранив пассажиров и вагоны. Рейс разбит на три акта по дистанции; награда зависит от спасённых пассажиров и уничтоженных врагов.
