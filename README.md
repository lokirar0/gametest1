# Rail Mayhem: Depot to Depot

Аркадная 3D-игра для браузера и Windows: играйте за стрелка от первого лица, перемещайтесь по крыше поезда, отбивайтесь от бандитов, чините вагоны и устанавливайте на них автономные турели. Между рейсами можно улучшать поезд в депо и тратить заработанные монеты в казино.

## Разработка в браузере

Требуется Node.js 20 или новее.

```bash
npm ci
npm run dev
```

Откройте адрес, который Vite покажет в терминале (по умолчанию `http://localhost:3000`).

## Запуск как приложение Windows

Для разработки в отдельном окне приложения:

```bash
npm ci
npm run desktop:dev
```

Для создания Windows-файлов запуска:

```bash
npm ci
npm run desktop:build
```

Готовые файлы появятся в папке `release`: `Rail-Mayhem-<версия>-<архитектура>.exe` запускается без установки, а `Rail-Mayhem-Setup-<версия>-<архитектура>.exe` устанавливает игру и создаёт ярлыки. Для сборки требуется Windows и Node.js 20 или новее.

Для проверки production-сборки:

```bash
npm run typecheck
npm run build
```

## Управление

- Нажмите на игровое окно, чтобы захватить мышь; мышь управляет обзором от первого лица.
- `W` / `A` / `S` / `D` — ходить по вагонам; удерживайте левую кнопку мыши, чтобы стрелять.
- `1` — бесконечный пистолет с малым уроном; `2` — автомат с мощными, расходуемыми патронами.
- `F` — перезарядить автомат; удерживайте `R`, чтобы вручную чинить повреждённый вагон под ногами.
- `T` — установить самонаводящуюся турель на вагон под ногами за 150 монет; турель сама ищет и атакует врагов.
- `E` или `Q` — гудок.

Доведите поезд до депо, сохранив пассажиров и вагоны. Рейс разбит на три акта по дистанции; награда зависит от спасённых пассажиров и уничтоженных врагов.
